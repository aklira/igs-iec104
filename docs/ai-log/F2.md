# F2 — Continuous integration

## Prompt (summarised)

Add `.github/workflows/ci.yml` running the standard gate of IMPLEMENTATION.md
(fmt, clippy with -D warnings, test with all features, cargo deny) plus a
coverage report with cargo llvm-cov (report only, not a threshold), on Linux.
The workflow must not need docs/spec/. The workflow should pass actionlint if
available, and the gate must pass locally.

## Summary

- `.github/workflows/ci.yml`: single `gate` job on ubuntu-latest; checkout,
  install cargo-deny and cargo-llvm-cov with taiki-e/install-action, then run
  fmt, clippy, test, coverage (summary) and deny. Triggered on push and pull
  request, with job-level concurrency cancelling superseded runs. Nothing
  references docs/spec/; the build works without the standards present.
- `rust-toolchain.toml`: added the llvm-tools-preview component so the pinned
  toolchain matches what cargo llvm-cov needs on CI.
- actionlint is not installed here; validated with a YAML parser and against
  the documented inputs of the two actions used. Note: the rust toolchain is
  provided by the GitHub runner image plus the rust-toolchain.toml pin; no
  dtolnay/rust-toolchain step is needed.
- Local check of every step: fmt, clippy, test, deny passed (see F1);
  `cargo llvm-cov --workspace --all-features --summary-only` ran green with a
  0 % total on the empty crates, which is expected and does not fail the job.

Review note: coverage thresholds arrive with task X3; the step stays
report-only until then.
