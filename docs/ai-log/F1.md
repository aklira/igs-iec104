# F1 — Workspace skeleton

## Prompt (summarised from the maintainer request)

Implement Phase 0 of IMPLEMENTATION.md. Task F1: create the Cargo workspace
skeleton with the four crates (`igs-iec104-codec`, `igs-iec104-link`,
`igs-iec104`, `xtask`), edition 2021, rust-version, a stable
rust-toolchain.toml, the workspace lints (forbid unsafe code in codec and
link; deny unwrap_used, expect_used, indexing_slicing and
arithmetic_side_effects in codec and link), a deny.toml allowing MIT,
Apache-2.0, BSD-2/3-Clause, ISC and Unicode-3.0, and an Apache-2.0 SPDX
header in every source file. The task is done when the standard gate
(fmt, clippy -D warnings, test, deny) passes on the empty crates.

## Summary

Files created:

- `Cargo.toml`: workspace with resolver 2, the four members, shared package
  metadata (edition 2021, rust-version 1.85, Apache-2.0, repository URL).
- `rust-toolchain.toml`: stable channel with the clippy and rustfmt components.
- `deny.toml`: licences allowed exactly as required; unknown registries and
  git sources denied; the advisory-db entry commented in case the default
  is not available offline.
- `crates/igs-iec104-codec/Cargo.toml` and `src/lib.rs`,
  `crates/igs-iec104-link/Cargo.toml` and `src/lib.rs`: link depends on
  codec; both crates `#![forbid(unsafe_code)]` and deny the four clippy
  lints; the test profile relaxes them so unit tests can unwrap.
- `crates/igs-iec104/Cargo.toml` and sources: empty library plus the two
  binary stubs `igs104-client` and `igs104-server`.
- `xtask/Cargo.toml` and `src/main.rs`: empty maintainer tool, not
  published.
- Every source file starts with the Apache-2.0 SPDX header.

Review notes:

- rust-version 1.85 is my choice (the plan only says the field must exist):
  it is the first stable that allows `[lints]` tables in Cargo.toml.
  Maintainers may prefer another floor.
- `cargo deny` reports warnings for the allowed licences that no dependency
  has encountered yet; with empty crates this is expected, not an error.
- Cargo.lock is committed (reproducible CI builds).
- The pre-existing uncommitted edit in `.gitignore` (ignoring AGENTS.md,
  IMPLEMENTATION.md and opencode.json) was left unstaged: it predates this
  task and IMPLEMENTATION.md is currently tracked, so ignoring it would be
  contradictory; a maintainer should decide.

Gate: fmt, clippy with -D warnings, test and `cargo deny check` all pass.
