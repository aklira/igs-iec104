# igs-iec104-codec

APCI framing and ASDU encoding/decoding for IEC 60870-5-104, without I/O.

Includes information elements, time formats, profile validation and an incremental
frame decoder. This is the protocol layer of
[igs-iec104](https://crates.io/crates/igs-iec104).

## Usage

Add `igs-iec104-codec = "0.1.0"` to your dependencies.

See the [API documentation](https://docs.rs/igs-iec104-codec) and the
[project repository](https://github.com/aklira/igs-iec104).
